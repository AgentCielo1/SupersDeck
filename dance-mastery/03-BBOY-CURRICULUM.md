# 03 — The Master Bboy Curriculum: Foundation to Expert

The most complete breaking syllabus we could assemble — synthesized from VincaniTV
(Vince "Vincanity" Horiuchi), B-Boy & B-Girl Dojo (Menno van Gorp's foundation course,
Roxrite's freezes & transitions, Ynot's toprock, the Perfect Practice Formula), STEEZY's
breaking programs (Kid David, Bboy Machine), Ken Swift's VII Gems / Breaklife school,
Storm's footwork theory and Trivium work, Red Bull BC One camps and guides, BreakDance
Decoded's written pedagogy (Erin Huang), Project Breakalign's injury-science conditioning
(Nefeli Tsiouti), the WDSF/Olympic judging criteria, and the injury-epidemiology
literature (IJSPT, 2025 Italian cohort). Where the community has consensus, we encode it;
where it has gaps (feedback, transitions, spaced re-drilling, adult bodies), we fix them
by design.

**Important note on time estimates:** all durations are community-consensus anchors for a
consistently practicing adult, not promises. The graph's prerequisites are the truth; the
calendar is a forecast.

---

## 1. What the curriculum must fix (the ten documented gaps)

Research into learner complaints (forums, Quora, BreakDance Decoded's community writing)
found ten failure modes of self-taught breaking. Each is answered by a specific design
feature:

| # | Gap | Our fix |
|---|---|---|
| 1 | No feedback loop ("nobody tells me what MY body does wrong") | Tiered camera feedback + guided video self-review (Doc 06 §4); checkpoints per move |
| 2 | Move amnesia (land it once, lose it next week — "a top reason people quit") | Spaced-repetition review queue; a move isn't "owned" until re-hit across sessions (Doc 05 Law 8) |
| 3 | The transition gap (moves taught, linking never) | Transitions are **first-class nodes**: every move node has entry/exit edges; combo nodes are curriculum |
| 4 | Can't freestyle | Freestyle frameworks trained from week 1 (camera-on "Type C" reps, concept prompts) |
| 5 | Foundation feels boring / value invisible | Foundation taught *with its purpose visible* (every foundation node shows the doors it opens); style layered early |
| 6 | No periodization or body care | Breakalign-style conditioning woven into the tree as attribute gates; power volume capped |
| 7 | Loneliness / no scene | The relatedness layer + graduated cypher ladder (Doc 05 §5) |
| 8 | Fragmented, unleveled content | The whole point of the skill graph |
| 9 | Musicality/culture taught last or never | Musicality + history are Phase 0 content, trained daily |
| 10 | No program designed for adult bodies | Adult-first loading: longer prep ramps, wrist/shoulder gates, recovery encoded |

## 2. Mastery, defined by the sport itself

The summit uses the axes breaking's own judges use — the WDSF **Trivium** system (created
by Storm and DJ Renegade) and its Paris 2024 evolution (five equal criteria):

**Technique · Vocabulary · Execution · Musicality · Originality** (20% each).

Consequences baked into the curriculum: pure power specialization and pure foundation
specialization are both competitively penalized — the tree forces breadth (Ken Swift's
VII Gems principle: master every specialty). "Execution" means *never crashing*: a move
graduates only at 10/10 clean in practice (the community's own battle-readiness rule).
Musicality is scored, so it is trained daily, not eventually — including improvising to
unknown music (the Olympic format).

## 3. The six phases

Each phase is 2–4 of Doc 05's Seasons. Phases overlap by design (you're polishing Phase 2
material while opening Phase 3). Gates between phases are skill demonstrations, never
calendar dates.

### Phase 0 — Ignition (Weeks 1–2, runs alongside Phase 1 forever)
The phase that exists because of *your* history: it is deliberately un-failable.
- **Musicality I**: counting 8s until automatic; find the 1; kick/snare isolation
  (step odds, clap evens); the breaks canon playlist — Apache, It's Just Begun, The
  Champ, Give It Up or Turnit a Loose, The Mexican, the Mardi Gras break.
- **Groove**: rocking on beat, in socks, in a bedroom. Nothing else.
- **Culture 101**: what breaking is, the Bronx, the cypher, the elements — 5-minute
  lessons. You can't master a culture you don't know.
- **Body audit**: wrist/shoulder/neck/hip baseline tests → personalizes every
  conditioning ramp that follows.
- Daily commitment: the 8-minute MVS only. Week one's only goal is 5 sessions (the
  activation number the retention data demands).

### Phase 1 — Foundation I (Months 1–3)
| Pillar | Nodes (in teaching order) | Anchors |
|---|---|---|
| Toprock | Two-step/cross step → Indian step → kick step → salsa step | steps performable in 1–2 weeks; *good* is a forever project |
| Get-downs | Corkscrew/squat drop → knee drop (taught as first-class content — the most-neglected element) | |
| Footwork | **6-step** (the axis of all footwork) → 3-step → 2-step | 6-step rough in days–2 weeks, smooth in 1–3 months |
| Freezes | Baby freeze → turtle freeze | baby freeze 1–2 weeks |
| Power prep | Backspin; wrist prep L1–L2 (GMB-style circles, palm rocks, wrist push-up ramp); wall headstand; hollow body | backspin: weeks |
| Meta | Freestyle rep from week 3 (camera on, one breakbeat, 60 seconds, no judgment); first combo node: toprock → drop → 6-step → baby freeze **on beat** | this combo IS the first battle round in miniature |

**Phase gate:** the mini-round clean 5 times on camera + 30s wall headstand + wrist prep L2.

### Phase 2 — Foundation II (Months 3–9)
| Pillar | Nodes | Anchors |
|---|---|---|
| Toprock | Brooklyn rock/uprock intro, Charleston, side/back steps; arm styling; personal bounce | |
| Get-downs | Sweep drop → hook drop → coin drop (VincaniTV staple) | |
| Footwork | **CCs** → coffee grinder/helicopter → hooks → kick-outs → switches → zulu spins | |
| Freezes | Chair freeze (root of airchair) → headstand freeze → shoulder freeze → handstand freeze | |
| Power | **Windmill** (gateway power move; prereqs: backspin + turtle + baby freeze, all now in place) → swipes | windmill ~1 month to ugly, 3–12 to clean/continuous |
| Conditioning | Shoulder prep L2 (scap push-ups, banding, wall handstand time); bridge L1; neck L1 (headstand accumulation); straddle/pancake ramp begins | |
| Meta | Musicality II: song mapping (count the 8s, find the break); round construction 101 (open → get-down → footwork → punctuation freeze); first **cypher-ladder step**: film a full round, share to crew | |

**Phase gate:** 2 continuous windmills; CC both directions; chair freeze held 3s on beat; one 45s round with zero "teleports" (every transition named).

### Phase 3 — Vocabulary & Power I (Months 9–18)
| Pillar | Nodes | Anchors |
|---|---|---|
| Footwork | Pretzels, W-drops, russian taps, baby swipe, threads I; backrock/bottom-rock entries (the "9 backrock entries" idea as a family of nodes) | |
| Freezes | Airbaby → elbow/forearm freeze; freeze *combos* (baby→chair→headstand chains, Roxrite "never crash" methodology) | |
| Power (choose 2 lanes, keep all warm) | **Head lane**: headstand taps → continuous headspin (beanie; 2–4wk headstand, 1–3mo taps, 6–12mo continuous) · **Floats lane**: turtle → handglide → cricket · **Mill lane**: munchmills/babymills, barrels · halos | |
| Conditioning | Neck L2, wrist L3, Copenhagen/adductor work (flare prep begins: mushroom-circle progression), bridge L2 | |
| Meta | Musicality III: one-instrument rounds; hitting horn stabs; set drilling methodology (30+30 rounds both directions, record runs 9–10 of 10); commando/routine basics if crew exists | |

**Phase gate:** one power lane at "clean" (e.g., 3 headspin taps→spin, or turtle→cricket x3); 90s of continuous varied footwork; freeze chain of 3 on beat.

### Phase 4 — Power II & Style (Months 18–36)
| Pillar | Nodes | Anchors |
|---|---|---|
| Power | **Flare** (via mushroom circles; prereqs: handstand strength, straddle compression — "skipping prerequisites is the #1 injury/plateau cause") → 1990/2000 → elbow spins | flare 6mo–2yr |
| Freezes | Airchair (6mo–2yr), hollowback prep → hollowback | |
| Tricks | Kip-up → suicides (front, coin-drop) → blow-up sequencing | |
| Style | Signature-move development (originality is 20% of the score): take 3 foundation moves and mutate them until they're yours; character work; threading language | |
| Meta | Battle craft I: set banks (opener / pressure / musicality / power / closer), Roxrite's attack-&-react reading; entering real cyphers (ladder: familiar → unfamiliar) | |

**Phase gate:** 3 flares OR clean 1990 + airchair; two signature moves witnesses recognize as yours; survive 3 rounds in an open cypher.

### Phase 5 — Airflare & Battle Mastery (Years 3–5+)
- **Airflare** (prereqs: solid mills + swipes + handstand strength, usually flares/90s
  first; 1–3+ years after windmill) → airflare combos (airflare→90, 1.5s).
- Full round economy: 1–7 round battles, unknown music, adaptive set selection; themed
  rounds (footwork-only, power-only, burner) as training constraints.
- Judging literacy: score your own filmed battles on the five Paris criteria; train the
  weakest axis each season.
- Teaching as mastery: "each one teach one" — coach a beginner (in-app or real); the
  VII Gems cross-specialty standard: you can answer *any* style in battle.

### The Expert Horizon (ongoing)
Elite reality check from the sports-science literature: pros in the IJSPT cohort train
~24 hrs/week with median 11 years in — and *skill, not general athleticism, separates
levels* (no strength/endurance differences between elite and developing breakers). The
adult-starter path targets **excellent, battle-ready, cypher-respected** on 7–10 hrs/week
— and the same literature says that is genuinely reachable; "too late at 21+" is a myth
the data doesn't support (pro unlikely, *good* absolutely).

## 4. The five pillars as living tracks (never "completed")

Toprock, get-downs, footwork, freezes, power each have Learned → Clean → Fast → Styled
ladders per node (Doc 05 Law 7), and the SRS queue keeps every owned node warm forever —
the direct fix for move amnesia. Transitions are edges *and* nodes: the graph literally
cannot recommend a new move without scheduling its entries and exits.

## 5. Session anatomy (what the generator builds daily — Doc 05 §3, breaking-tuned)

1. Warm-up: wrists/shoulders/neck circuits + toprock grooving (toprock's traditional
   warm-up role).
2. Power/technical attempts **early while fresh** (low-rep clusters).
3. Drilling block: interleaved SRS moves, both directions.
4. Set/combo training: run the current round; fix exactly one flaw per run.
5. Freestyle block: camera on, breakbeat, improvise (Type C).
6. Conditioning finisher + cool-down stretch (the most-skipped component — so it's inside
   the streak, not after it).

Worst-day MVS: toprock groove (1 song) + 1 SRS move + wrist circuits. Still counts.

## 6. The body-preparation spine (Breakalign-informed)

The injury evidence is stark: >95% of breakers report musculoskeletal injury; knee ~64%,
shoulder ~61%, wrist ~58%; intensive power practice correlates with shoulder pathology;
and **generic warm-ups showed no protective effect** — breaking-specific conditioning is
the only evidenced answer. So conditioning is not a sidebar; it is load-bearing graph
structure:

- **Wrist ramp L1–L4** (circles → palm/reverse rocks → wrist push-up variants → loaded
  fingertip work) — gates all floats and handstand work.
- **Shoulder ramp** (scap push-ups → banding → wall handstand accumulation → crow/frog →
  turtle weight-shifts) — gates windmill volume, flares, airflare.
- **Neck ramp** (headstand time → isometrics) — gates headspin taps; beanie mandatory.
- **Bridge/backbend ramp** — gates hollowback, airchair, macaco.
- **Hips** (straddle compression, pancake, Copenhagen) — gates flare lane.
- **Volume caps**: power-move attempt budgets per session/week (shoulder-pathology
  evidence); knee-drop technique taught with padding progressions ("fake-painful," not
  actually painful).
- Deload weeks are the off-season weeks of Doc 05's Seasons.

## 7. Musicality & culture track (daily, forever)

Counting → layer isolation → song mapping → one-instrument rounds → hitting accents →
unknown-music improvisation. Plus the history modules: the Bronx origins, Rock Steady,
the breaks canon and *why* those records, cypher etiquette, battle lineage (Freestyle
Session, BOTY, UK Champs, BC One, the Olympics), and the nomenclature Ken Swift fought to
preserve — a master bboy speaks the language.
